# Vesso

Responsive landing page for Vesso, built as a Frontend Developer test based on the provided design brief.

## Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite
* Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL provided by Vite.

## Purpose

This project was created as part of a Frontend Developer test, with a focus on responsive implementation, component structure, and translating the provided brief into a functional web interface.
